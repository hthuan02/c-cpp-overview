# Bài tập toán tử tăng giảm ++ --

## LEVEL 1 --- Nhận biết ++ và --

### Câu 1 --- Basic

``` c
int x = 10;

x++;

printf("%d", x);
```

Tìm giá trị của `x`.

------------------------------------------------------------------------

### Câu 2 --- Basic

``` c
int x = 10;

++x;

printf("%d", x);
```

Tìm giá trị của `x`.

------------------------------------------------------------------------

### Câu 3 --- Basic

``` c
int x = 10;

x--;

printf("%d", x);
```

Tìm giá trị của `x`.

------------------------------------------------------------------------

### Câu 4 --- Basic

``` c
int x = 10;

--x;

printf("%d", x);
```

Tìm giá trị của `x`.

------------------------------------------------------------------------

### Câu 5 --- Basic

``` c
int x = 5;

x++;
++x;
x--;
--x;
```

Sau mỗi câu lệnh, xác định giá trị của `x`.

## Câu 39

``` c

       x, y, a, b, c, d);
```

## Câu 40

``` c
int x = 10;
int y = 5;

int a = x--;
int b = ++y;

x++;
y--;

int c = --x;
int d = y++;

int e = x + y + a + b + c + d;
```

Tìm:

    x, y, a, b, c, d, e

------------------------------------------------------------------------

# Ghi nhớ

    ++x  -> tăng trước, dùng giá trị mới
    x++  -> dùng giá trị cũ, tăng sau

    --x  -> giảm trước, dùng giá trị mới
    x--  -> dùng giá trị cũ, giảm sau
